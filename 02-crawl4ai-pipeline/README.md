# 🐙 Blueprint 02: Crawl4AI High-Performance Crawler

Production setup for **Crawl4AI** (asynchronous, LLM-friendly web scraping engine).

Accompanies the masterclass: **[Crawl4AI: The High-Performance Open-Source LLM Web Crawler (4K Blueprint)](https://youtu.be/qonYs-SIuU0)**.

---

## 🚀 Quickstart

1. **Start Self-Hosted API Server** :
   ```bash
   docker compose up -d
   ```

2. **Run Local Async Crawler** :
   ```bash
   pip install crawl4ai
   python crawler_sample.py
   ```
